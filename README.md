# ผังจุดวางถังขยะแยกประเภท — โรงงาน HAMER

เครื่องมือ **ไฟล์เดียวจบ (single-file HTML)** สำหรับมาร์กจุดวางถังขยะแยกประเภทบนผังโรงงาน
ดูได้ 3 มุมมอง และส่งออกเป็นเอกสาร PDF สำหรับนำเสนอผู้บริหาร

## เปิดใช้งาน

- **บนเว็บ:** เปิดลิงก์ GitHub Pages ของ repo นี้ได้เลย (ใช้ได้ทั้งคอมและมือถือ)
- **ออฟไลน์:** ดาวน์โหลด `index.html` แล้วดับเบิลคลิก — ทำงานได้ครบโดยไม่ต้องติดตั้งอะไร

## ความสามารถ

| หัวข้อ | รายละเอียด |
|---|---|
| **3 มุมมอง** | 2 มิติ (ผังพื้น) · ไอโซเมตริก 2.5 มิติ · 3 มิติ หมุนรอบได้ (three.js) |
| **มาร์กจุดเอง** | คลิกบนแผนผังเพื่อวางถัง · ลากย้าย · ลบ · ย้อนกลับได้ |
| **ถัง 3 ประเภท** | 🟢 ขยะเปียก · 🔵 ขยะทั่วไป · 🟡 ขยะรีไซเคิล (ใช้รูปถังจริงของโรงงาน) |
| **ตรวจพื้นที่อัตโนมัติ** | วางถังตรงไหน ระบบบอกเองว่าอยู่อาคาร/พื้นที่ใด |
| **ส่งออก PDF** | เอกสาร A4 แนวนอน: ปก → ผัง 2 มิติ → ภาพจำลอง 3 มิติ → ทะเบียนจุดวาง + ช่องลงนาม |
| **เก็บข้อมูล** | บันทึกลงเครื่องอัตโนมัติ (localStorage) + สำรอง/กู้คืนเป็นไฟล์ JSON |

## วิธีใช้แบบรวบรัด

1. เลือกประเภทถังจากแถบซ้าย (หรือกดปุ่ม `1` `2` `3`)
2. คลิกตำแหน่งบนแผนผัง → ถังจะถูกวางพร้อมรหัสจุด `WP-01`, `WP-02`, …
3. คลิกถังที่วางแล้วเพื่อแก้ประเภท / จำนวน / หมายเหตุ
4. กรอก "ข้อมูลเอกสาร" (เลขที่เอกสาร ผู้จัดทำ หน่วยงาน)
5. กด **ส่งออก PDF** → ในหน้าต่างพิมพ์เลือก **Save as PDF · A4 · แนวนอน · Margins = None** และเปิด **Background graphics**

### คีย์ลัด

| ปุ่ม | ทำอะไร |
|---|---|
| `1` `2` `3` | เลือกถังเขียว / น้ำเงิน / เหลือง |
| `Esc` | ยกเลิกการเลือก |
| `Delete` | ลบถังที่เลือกอยู่ |
| `Ctrl` + `Z` | ย้อนกลับ |

### พารามิเตอร์ URL

| พารามิเตอร์ | ผลลัพธ์ |
|---|---|
| `?test=1` | รันชุดทดสอบในไฟล์ (43 เคส) แล้วแสดงผลมุมขวาล่าง |
| `?debug=1` | เปิดแผงดีบักแสดงค่าสถานะจริงขณะทำงาน |

## ที่มาของผัง

ผังทั้งหมดถอดพิกัดมาจากไฟล์ Lay-Out ต้นฉบับของโรงงานโดยตรง (ไม่ได้วาดประมาณ) ได้ **29 พื้นที่ + ถนน 5 เส้น**
ชื่ออาคารใช้ตัวย่อตามที่ปรากฏในไฟล์ต้นฉบับทุกตัว

> **หมายเหตุ:** ความสูงของอาคารในมุมมอง 3 มิติเป็นค่าจำลองเพื่อการนำเสนอ ไม่ใช่ค่าจริงจากแบบก่อสร้าง

## เทคนิคที่ใช้

- Vanilla JavaScript ล้วน — ไม่มี build step ไม่มี framework
- [three.js](https://threejs.org/) r180 ผ่าน CDN สำหรับมุมมอง 3 มิติ
  (ถ้าโหลดไม่สำเร็จ/ไม่มีเน็ต แอปจะสลับไปใช้มุมมองไอโซเมตริกให้อัตโนมัติ และส่งออก PDF ได้ตามปกติ)
- ฟอนต์ IBM Plex Sans Thai · Noto Serif Thai · Playfair Display จาก Google Fonts
- ส่งออก PDF ด้วย `window.print()` + `@media print` — ตัวอักษรไทยคมชัดแบบ vector

## การทดสอบ

ชุดทดสอบ 43 เคสฝังอยู่ในไฟล์เดียวกัน เปิดด้วย `index.html?test=1`
ครอบคลุม: การตรวจพื้นที่จากพิกัด, การสรุปยอด, การจัดกลุ่มตามโซน, การแปลงพิกัดไอโซเมตริก,
การอัปเกรดโครงสร้างข้อมูลเก่า (migrate), การจัดป้ายชื่อไม่ให้ล้นกรอบ และการกันค่าว่าง/ค่าผิดรูปแบบ
